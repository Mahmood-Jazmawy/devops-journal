# Linux Cheatsheet

1. `pwd` - Shows my current working directory.
2. `ls` - Lists files and directories.
3. `cd` - Changes my current directory.
4. `mkdir` - Creates a directory.
5. `touch` - Creates an empty file.
6. `cat` - Prints the contents of a file.
7. `grep` - Searches for matching text in a file.
8. `wc`	- Counts lines, words or characters.
9. `cp`	- Copies files or directories.
10. `mv` - Moves or renames files.
